Restaurant API

This Django application provides menu and table-booking APIs.

  • Browse menu items
  • View table bookings
  • Open admin dashboard

Use an API client such as Insomnia to create or update records. Write operations require a token.

Registration endpoint: POST /api/auth/register/

Token endpoint: POST /api/auth/token/
